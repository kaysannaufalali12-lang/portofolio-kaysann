## 🎯 Fitur & Struktur Halaman

---

## 🎨 Desain & Teknologi (Tech Stack)
- **HTML5:** Struktur semantik dokumen web (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`).
- **CSS3:** 
  - Tema *Modern Tech Dark Mode* dengan variabel CSS (`:root`).
  - Layout responsif menggunakan **CSS Grid** dan **Flexbox**.
  - *Sticky Navigation Bar* dengan efek *glassmorphism* (`backdrop-filter`).
  - *Form styling* interaktif dan efek *hover* pada kartu/tombol.
